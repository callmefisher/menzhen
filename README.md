# 惊蛰 — 专为中医诊所打造的智慧管理系统

> 一套系统，管好一家诊所。从挂号到开方，从库存到回访，从经络教学到 AI 辅助辩证——让中医师专注于看病，让管理不再是负担。

---

## 为什么需要惊蛰？

中国有超过 **70 万家** 中小中医诊所。绝大多数还在用纸质病历、手写处方、Excel 管库存。市面上的 HIS 系统要么太贵（年费数万），要么太重（培训一周），要么完全忽略了中医的特殊需求——脉象、舌象、经络穴位、方剂加减、五运六气。

**惊蛰**从第一行代码就为中医场景设计，既能在诊所局域网内独立运行（断网也不影响），也能多诊所云端共享、统一管理

## 核心能力一览

### 1. 患者全生命周期管理

从患者第一次到诊，到每次复诊、开方、收费、回访——**一条完整的诊疗链路**，清晰可追溯

- **电子建档**：姓名、性别、生日（自动算年龄）、电话、身份证、住址、籍贯、体重、备注，一次录入，终身可查
- **诊疗记录**：主诉、脉象（下拉搜索 + AI 智能匹配）、舌象（拍照上传 + AI 分析）、诊断、治疗方案，每次就诊自动关联患者
- **附件管理**：支持图片、音频、视频上传，舌象照片直接关联病历
- **操作留痕**：所有关键操作（新增、修改、删除）全程记录，新旧数据快照对比，满足合规审计需求

### 2. AI 智能辅助——中医师的"第二大脑"

我们接入了大语言模型（DeepSeek），但不是让 AI 替代医生，而是让 AI 做医生的**知识助手**：

- **辩证论治分析**：输入症状，AI 从中医学、现代医学等多维度给出分析参考，结果自动缓存
- **舌象智能分析**：描述或上传舌象，AI 返回详细解读
- **中药/方剂/脉象智能查询**：数据库没有？AI 自动查询并入库，**系统越用越聪明**
- **五运六气**：选择年份，AI 流式输出当年运气分析，辅助季节性用药参考

> AI 功能为可选模块，不配置 API 密钥也不影响系统正常使用。

### 3. 电子处方与智能开方

- 从方剂库**一键开方**，自动填充药物组成和剂量
- 草药（按克）和中成药（按盒）**双区域管理**，自动查询库存
- 处方打印：多列排版（每 10 味一列），清晰美观
- 开方时**实时显示库存**，避免开出无药可配的处方

### 4. 库存与收费——诊所的"钱袋子"

- **药物库存**：支持本草和成药两大分类，单个入库 + 批量导入，货架号管理
- **库存预警**：低于阈值自动红色高亮，显示货架号快速定位补货
- **智能收费**：从处方自动计算药费（本草按克单价 × 用量 × 剂数，成药按盒计价），支持诊金编辑
- **库存扣减**：收费时一键扣除库存，事务保证数据一致性，已扣库存防重复
- **收费单打印**：逐项明细，清晰透明

### 5. 排队叫号与预约管理——让候诊有序可控

- **接诊医生配置**：管理员指定哪些医生今日接诊、诊室号码
- **叫号大屏**：医生卡片网格 + 实时 WebSocket 推送，叫号声音提醒
- **预约系统**：患者可提前预约指定医生的时段，到诊日自动入队
- **时段矩阵**：可视化查看每位医生每个时段的预约容量与余量
- **自助预约**：患者通过手机门户自行预约，减少前台人工操作
- **预约签到**：患者到场后签到确认，状态自动流转

### 6. 患者自助门户——让患者动起来

患者无需来诊所排队，手机扫码即可自助完成全流程：

- **手机登录**：手机号注册/登录，支持多诊所切换
- **在线预约**：查看医生出诊日历，选择时段预约
- **自助取号**：排队前自助取号，查看当前候诊人数
- **查看记录**：随时查看本人的历次诊疗记录（只读）
- **账单查询**：查看每次就诊的费用明细
- **功能开关**：管理端可按诊所需求关闭/开启各项患者门户功能

### 7. 回访管理——让每位患者都被记住
- 待回访 / 已完成 / 逾期 三态自动追踪
- 统计面板一目了然：今日待回访、逾期提醒、康复标记
- 支持电话、微信、到诊等多种回访方式

### 8. 经络穴位 3D 可视化——中医教学的未来

这是我们最引以为傲的功能，也是市面上**几乎没有竞品**的能力：

- **交互式 3D 人体模型**：男/女双模型，自由旋转缩放
- **20 条完整经络路径**：水流动画效果，直观展示经络走向
- **367 个穴位标记**：点击即查详情（五输穴、原穴、络穴等属性）
- **教学资源**：经络配套教学视频和古籍出处

> 适用于诊所内部培训、实习生教学、患者科普。

### 9. 中医知识库

- **脉象库**：20+ 种脉象，按浮、沉、迟、数等分类，含特征、主病、临床意义
- **临床经验集**：记录机构积累的用药经验，全诊所共享，**把老中医的经验数字化**
- **二十四节气养生**：按节气推送养生建议，贴合中医"天人合一"理念
- **易理/卦象**：64 卦完整数据库，含中医应用解读（可选模块）

## 多诊所？没问题

惊蛰从底层架构就支持**多租户**——每家诊所的数据严格隔离，互不可见：

| 特性 | 说明 |
|------|------|
| **数据隔离** | 患者、病历、处方、库存、收费、回访、预约——每家诊所独立，绝不串数据 |
| **角色权限** | 39 个细粒度权限码，可自定义角色（医生只能看诊，药房只管库存） |
| **诊所自治** | 诊所管理员可管理本所员工和角色，无需联系平台 |
| **患者门户隔离** | 患者账号独立于员工账号，独立 JWT（30 天有效），仅可查看本人在本诊所的数据 |
| **无缝切换** | 同一账号可归属多个诊所，切换时自动刷新权限 |

> 一台服务器管一家诊所，也能一台服务器管一百家诊所。

## 部署极简——5 分钟上线

不需要专业 IT，不需要买服务器机房。一台普通电脑就能跑起来。

### 零基础一键安装（推荐）

下载一个文件，双击即可，脚本自动安装所有依赖：

| 操作系统 | 安装方式 |
|----------|-----------|
| Windows | 下载 [`start-wizard.bat`](https://raw.githubusercontent.com/callmefisher/menzhen/main/start-wizard.bat)，**右键 → 以管理员身份运行**（[镜像下载](https://cdn.jsdelivr.net/gh/callmefisher/menzhen@main/start-wizard.bat)） |
| macOS / Linux | 终端运行下方命令 |

**macOS / Linux 一键安装命令：**

```bash
mkdir -p ~/menzhen && cd ~/menzhen && curl -fLO "https://raw.githubusercontent.com/callmefisher/menzhen/main/start-wizard.command" && bash start-wizard.command
```

> 如果下载失败（国内网络），使用镜像源：
>
> ```bash
> # 镜像源 1：jsDelivr CDN
> mkdir -p ~/menzhen && cd ~/menzhen && curl -fLO "https://cdn.jsdelivr.net/gh/callmefisher/menzhen@main/start-wizard.command" && bash start-wizard.command
>
> # 镜像源 2：ghfast 代理
> mkdir -p ~/menzhen && cd ~/menzhen && curl -fLO "https://ghfast.top/https://raw.githubusercontent.com/callmefisher/menzhen/main/start-wizard.command" && bash start-wizard.command
> ```

> 详细步骤见 [裸机安装指南](docs/bare-metal-install-guide.md)

### 开发者快速部署（已有 Docker + Git）

```bash
git clone <repo-url> && cd menzhen
./deploy.sh
```

**就这一行命令**，系统自动完成：
- 生成安全密钥（数据库密码、JWT 签名、对象存储密钥）
- 构建全部 6 个服务容器
- 启动 MySQL、MinIO、后端 API、前端、Nginx、备份守护进程
- 健康检查确认所有服务正常

打开浏览器访问 `http://localhost`，用默认账号 `admin / admin123` 登录即可。

### 全平台适配

- **电脑端**：完整功能，表格展示，高效操作
- **手机/平板**：响应式布局自动适配，侧边栏变抽屉菜单，表格变卡片列表，触控友好

### 数据安全，自动守护

- **MySQL 备份**：每 2 小时自动快照
- **文件备份**：每 12 小时自动打包
- **云端同步**：自动上传至七牛云对象存储（可选）
- **多服务器隔离**：通过 `SITE_ID` 区分不同服务器的备份，互不干扰
- **配置热加载**：备份相关配置（七牛云、备份间隔）修改后自动生效，无需重启
- **一键恢复**：`./deploy.sh --restore /path/to/backup`，一条命令恢复全部数据
- **本地+云端双清理**：默认各保留最新 5 份，不占多余空间
- **存储清理**：删除/更新病历自动清理 MinIO 旧文件，支持孤立文件扫描与批量清理
- **磁盘监控**：实时监控磁盘/MySQL/MinIO 使用率，支持 MySQL 数据目录在线迁移和备份目录变更
- **租户数据迁移**：上传旧系统备份，解析后将指定租户数据导入当前系统

## 技术架构

> 写给技术合伙人和投资人看的部分。

| 层 | 技术选型 | 为什么选它 |
|---|---------|-----------|
| 前端 | React 19 + TypeScript + Ant Design 6 | 企业级 UI 组件库，开发效率高，生态成熟 |
| 3D 可视化 | Three.js + React Three Fiber + BVH | 浏览器原生 3D，无需安装插件，性能优秀 |
| 后端 | Go + Gin + GORM | 编译型语言，单文件部署，并发性能强，适合诊所级到平台级 |
| 数据库 | MySQL 8.0 | 最成熟的关系型数据库，运维资料丰富 |
| 文件存储 | MinIO（S3 兼容） | 私有部署的对象存储，舌象/附件统一管理 |
| AI | DeepSeek API | 国产大模型，中医药知识优秀，成本可控 |
| 部署 | Docker Compose + Nginx | 一键部署，环境一致性好，迁移简单 |

### 架构亮点

- **离线优先**：所有核心功能不依赖外网，AI 为增值模块
- **多租户隔离**：数据库层面 `tenant_id` 强隔离，不是应用层过滤
- **AI 自学习回路**：查询 → 数据库没有 → AI 补全 → 自动入库 → 下次直接命中，知识库越用越丰富
- **Token 版本机制**：租户切换时 token 版本号 +1，旧 token 自动失效，无需手动退出重登
- **全量审计日志**：每次数据变更记录新旧值快照，满足医疗行业合规要求

## 项目结构

```
menzhen/
├── server/              # Go 后端（API 服务）
│   ├── handler/         # 请求处理（20+ 业务模块）
│   ├── middleware/       # 认证（员工 JWT + 患者门户 JWT）、权限、租户隔离、审计
│   ├── model/           # 37 个数据模型
│   ├── service/         # 业务逻辑 + AI 客户端
│   └── storage/         # MinIO 文件存储
├── web/                 # React 前端
│   └── src/
│       ├── pages/       # 20+ 页面模块（含患者门户 /patient/* 独立路由）
│       ├── components/  # 通用组件（布局、处方、打印、磁盘监控等）
│       └── api/         # 后端 API 封装（25+ API 模块）
├── scripts/             # 备份、恢复、数据播种脚本
├── nginx/               # 反向代理配置
├── docker-compose.yml   # 6 服务编排
├── deploy.sh            # 一键部署入口
└── docs/                # 设计文档与运维手册
```
