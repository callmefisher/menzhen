WebSocket 独立公共模块（新建）

后端：新建 ws/hub.go + ws/client.go，独立于现有代码

前端：新建 useWebSocket hook，独立于现有轮询机制

不修改：库存预警、回访等已有红点逻辑完全不变

复用场景：处方通知（当前）、预约排队、未来实时需求

消息格式：{"type":"rx_notify"|"rx_done"|"rx_cleanup","payload":{...}}

降级：断连时自动降级 30s 轮询，恢复后重连

红点逻辑（复用现有样式，独立数据源）

触发：WebSocket 收到 rx_notify → 红点数字 +1

消除：点击「标记已抓药」→ WebSocket 推送 rx_done → 红点 -1

显示：未抓药处方数量，>99 显示 99+

数据保留策略（仅 1 天）

后端：定时任务每小时清理超过 24h 的记录

前端同步：WebSocket 推送 rx_cleanup，前端移除对应条目

已抓药：标记完成后移入「已完成」tab，24h 后自动清理

场景：进入库存药物页，顶部处方通知列表。未完成显示「未抓药」，已完成显示「已抓药 ✓」。
