# 排队叫号系统 — 设计文档

## 概述

为门诊管理系统新增排队叫号功能，支持全局看板、医生叫号、患者列表联动、移动端适配、跨天自动清理。

## 使用场景

- **主操作者**：医生在诊室内电脑上操作叫号/完成就诊
- **移动端**：医生偶尔用手机查看排队情况（只读为主）
- **清空权限**：管理员可一键清空全部排队信息

- 新增菜单项「📢 排队叫号」，路由 `/queue`

### 自适应规则

| 医生数 | 布局 |
|--------|------|
| 1 | 全宽单卡片 |
| 2 | 左右并排 |
| 3-4 | 2×2 网格 |
| 5+ | 2×N 网格，页面整体滚动 |

### 队列行样式（3种状态）

1. **就诊中**：绿色左边框 `#52c41a` + 淡黄底 `#fffff0` + 绿色渐变号码牌 + 绿色描边标签「就诊中」
2. **请准备**：橙色左边框 `#fa8c16` + 淡橙底 `#fff7e6` + 橙色渐变号码牌 + 橙色描边标签「请准备」+ 呼吸闪烁动画
3. **候诊中**：蓝色左边框 `#1677ff` + 淡蓝底 `#f0f7ff` + 蓝色渐变号码牌 + 绿色描边标签「候诊中」

### 交互功能

- **自动滚动**：滑块控速（停/极慢/慢/中/快/极快），默认停止，鼠标悬停暂停
- **Hover提示**：悬停患者行显示黑色气泡「当前就诊」/「下一位就诊」/「前方还有N位」
- **现场取号**：输入姓名+选医生→取号→新患者滑入动画→badge弹跳→toast提示→统计更新
- **一键清空**：需管理员权限，二次确认弹窗

### 叫号弹窗（卡片内独立）

- 每个医生卡片头部有「📢 叫号」按钮
- 就诊中患者行右侧有「再次叫号」按钮
- 弹窗**在对应医生卡片内**弹出（`position:absolute` 覆盖卡片区域），各医生独立互不干扰
- 弹窗内容：流光顶部 + 大号码（渐变色）+ 姓名 + 诊室信息 + 确定按钮
- **15秒**进度条倒计时，自动关闭
- 再次叫号：取消当前弹窗，立刻弹出新的（重置15秒）

## 第2阶段：患者列表页联动

### 2A 管道式叫号条

患者列表页（`/patients`）顶部新增管道式叫号条，只显示当前登录医生的队列：

```
┌───────────────────────────────────────────────┐
│ [15等候]──› 008王秋月 › 007高志远 › 006吴丽华 › 005钱大海 ●●● [请准备 004周雪梅] ●●● [就诊中 003孙志强 ✓完成] │
└───────────────────────────────────────────────┘
```

- **等候池**（最左）：蓝色渐变区域，显示等候总人数，三角箭头连接管道
- **队列管道**（中间）：灰色芯片从浅到深，`›` 分隔
- **流动光点**：橙色/绿色小点在芯片间脉冲流动，表达方向感
- **请准备**：橙色光晕 + 渐变标签，从管道中凸显
- **就诊中**（最右）：绿色渐变独立区域，三角箭头，大号码牌 + 完成按钮

### 2B 表格行状态联动

- 就诊中的患者行：绿色左渐变背景 `linear-gradient(90deg,#f6ffed,#fffff8)` + 绿色下边框
- 请准备的患者行：橙色左渐变背景 `linear-gradient(90deg,#fff7e6,#fffef8)` + 橙色下边框
- 姓名后显示状态标签（与队列行样式一致）

### 患者列表叫号联动

- 患者列表页的「开始/叫号」按钮通过 WebSocket 或共享状态联动触发排队叫号页对应医生卡片内的弹窗
- 就诊中患者行的「再次叫号」按钮同样联动

## 2E 跨天自动清理（后端）

### 一键清空

- API：`POST /api/v1/queue/clear`
- 权限：需管理员权限（`queue:clear`）
- 清空当前租户今日所有排队信息
- 前端二次确认弹窗

### 跨天自动清理

- **服务器启动时**：检查最后一条排队记录的日期，如果与当前日期不同（跨天），自动清理所有排队信息
- **定时任务**：每天 00:01 执行一次检查，跨天即清理
- 判断逻辑：`lastQueueDate < today`（只要跨天，即使是00:00:01也清理）
- 清理范围：当前租户的所有排队信息（多租户隔离）

## 数据模型

### QueueEntry（排队条目）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | uint | 主键 |
| tenant_id | uint | 租户ID |
| patient_id | uint | 患者ID（可空，现场取号） |
| patient_name | string | 患者姓名 |
| doctor_id | uint | 医生用户ID |
| doctor_name | string | 医生姓名 |
| room | string | 诊室名 |
| seq_number | int | 排队序号（当日自增） |
| status | string | `waiting` / `ready` / `seeing` / `done` / `missed` |
| booked_time | string | 预约时间 |
| arrival_time | *time.Time | 到达时间 |
| called_at | *time.Time | 最后叫号时间 |
| completed_at | *time.Time | 完成时间 |
| source | string | `walk_in` / `appointment` |
| queue_date | date | 排队日期（用于跨天清理判断） |
| created_at | time.Time | 创建时间 |

索引：`(tenant_id, queue_date, status)` 覆盖索引

### QueueSeq（序号计数器）

| 字段 | 类型 | 说明 |
|------|------|------|
| tenant_id | uint | 租户ID |
| queue_date | date | 日期 |
| last_seq | int | 当日最后序号 |

## API 设计

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| GET | `/queue` | 获取今日队列（可按doctor_id筛选） | `queue:read` |
| POST | `/queue/take` | 现场取号 | `queue:create` |
| POST | `/queue/:id/call` | 叫号（状态→seeing，记录called_at） | `queue:update` |
| POST | `/queue/:id/complete` | 完成就诊（状态→done，自动叫下一位） | `queue:update` |
| POST | `/queue/:id/miss` | 过号 | `queue:update` |
| POST | `/queue/:id/requeue` | 重排（过号后重新排队） | `queue:update` |
| POST | `/queue/clear` | 一键清空 | `queue:clear`（管理员） |
| GET | `/queue/stats` | 统计数据（各状态计数） | `queue:read` |

### WebSocket 消息类型

| type | 说明 | payload |
|------|------|---------|
| `queue_call` | 叫号通知 | `{doctor_id, seq, patient_name, room}` |
| `queue_update` | 队列变更（取号/完成/过号等） | `{action, entry}` |
| `queue_clear` | 队列已清空 | `{}` |
