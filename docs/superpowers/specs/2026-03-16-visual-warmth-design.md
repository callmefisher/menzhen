# Visual Warmth Design - 温馨自然视觉优化

## 概述
对患者管理列表、病历列表、中药查询、方剂查询四个页面进行视觉色彩优化，同时全局联动侧边栏、Header、背景色，打造温馨自然的中医诊所系统风格。后续可扩展到全站。

## 设计风格
**温馨自然** — 暖绿+木色系，柔和阴影，自然亲和，降低患者紧张感。

### 色板
| 用途 | 颜色 | 色值 |
|------|------|------|
| 主色 | 生机绿 | `#52C41A` |
| 辅色 | 暖橙 | `#FA8C16` |
| 木色 | 木质棕 | `#D4B896` |
| 背景 | 奶白 | `#FAFAF5` |
| 侧边栏 | 深木色 | `#2C1810` |
| Header渐变 | 奶白→木色 | `#FAFAF5 → #F5EFE6` |
| 卡片背景 | 暖白 | `#FFFEF9` |
| 性别男 | 天蓝 | `#69B1FF` |
| 性别女 | 粉红 | `#FF85C0` |
| AI标签 | 渐变蓝紫 | `linear-gradient(135deg, #667eea, #764ba2)` |
| 本地标签 | 叶绿 | `#95DE64` |
| 中药分类 | 多彩系列 | 按分类映射不同暖色 |

### 视觉效果
1. **渐变边框/背景**：搜索栏、卡片、标签使用微妙渐变
2. **Hover 微动效**：卡片悬浮 `translateY(-2px)` + 阴影加深，按钮 scale(1.02)
3. **状态标签彩色化**：性别、AI来源、中药分类等用柔和彩色胶囊标签
4. **空状态插画**：无数据时显示 SVG 插画（中药草/方剂古籍/诊疗本等元素）

## 改动范围

### Phase 1：全局基础
1. **ConfigProvider theme token**：primaryColor → `#52C41A`，borderRadius → 12，colorBgLayout → `#FAFAF5`
2. **侧边栏**：背景色 `#2C1810`（深木色），标题字体暖色
3. **Header**：背景渐变 `#FAFAF5 → #F5EFE6`
4. **index.css**：添加 CSS 变量、卡片动效 class、温馨标签样式

### Phase 2：PatientList 页面
- 外层 Card：`#FFFEF9` 背景 + 大圆角 16px
- 搜索栏：输入框圆角 + 搜索按钮渐变绿
- 移动端卡片：左侧绿色竖条 + hover 微浮 + 性别彩色标签
- 桌面端表格：行 hover 暖色背景 `#FFFEF0`
- 空状态：患者插画 SVG

### Phase 3：RecordList 页面
- 搜索栏样式统一
- 移动端卡片：诊断摘要行暖色底 + 日期标签温暖橙
- 桌面端表格：行 hover + 诊断列渐变色文字
- 空状态：诊疗本插画 SVG

### Phase 4：HerbSearch 页面
- 搜索栏：大号搜索框渐变边框
- 分类标签：按中药分类映射不同暖色
- AI来源标签：渐变蓝紫胶囊
- 移动端卡片：展开区域柔和渐变背景
- 空状态：中药草插画 SVG

### Phase 5：FormulaSearch 页面
- 搜索栏样式统一
- 方剂名：暖棕色字体
- 药物组成：标签化展示（每味药一个胶囊标签）
- AI标签统一渐变样式
- 空状态：古方卷轴插画 SVG

## 技术实现
- Ant Design ConfigProvider theme token 覆盖
- CSS 变量 + CSS class（index.css）
- 组件内 inline style 精细调整
- SVG 空状态插画内联
- 移动端通过 `useIsMobile` 适配
- 所有动效 `transition: all 0.3s ease`

## 兼容性
- 桌面端 + 移动端响应式
- 遵循现有 `isMobile` 适配模式
- 不改变功能逻辑，纯视觉层改动
