# 服务器版安装教程（小白图文指南）

本教程适用于 **Ubuntu Server / CentOS** 等没有桌面的 Linux 服务器。

如果您用的是 **苹果电脑** 或 **Windows 电脑**，不需要看这个教程，直接双击 `start-wizard.command`（Mac）或 `start-wizard.bat`（Windows）即可。

---

## 您需要准备什么

| 物品 | 说明 |
|------|------|
| 一台 Linux 服务器 | 已通电、已联网、知道 IP 地址 |
| 您自己的电脑或手机 | 用来操作，需要有浏览器 |
| 服务器的登录账号和密码 | 一般是安装系统时设置的 |

> **如何获取服务器 IP 地址？**
> 如果您在服务器面前，登录后输入 `ip addr` 或 `hostname -I`，屏幕会显示一串数字（如 `192.168.1.100`），这就是 IP 地址。

---

## 第一步：连接到服务器

您需要从自己的电脑"远程连接"到服务器，这个操作叫 **SSH**。

### 苹果电脑 (Mac)

1. 打开 **终端**（在"启动台"里搜索"终端"，或按 `Command + 空格` 搜索 `Terminal`）
2. 输入以下命令，把 `用户名` 和 `服务器IP` 换成实际的值：

```
ssh 用户名@服务器IP
```

**举例：** 如果用户名是 `root`，服务器 IP 是 `192.168.1.100`：

```
ssh root@192.168.1.100
```

3. 第一次连接会问 `Are you sure you want to continue connecting?`，输入 `yes` 然后按回车
4. 输入密码（输入时屏幕不会显示任何字符，这是正常的），按回车
5. 看到类似 `root@server:~$` 的提示符，说明连接成功了

### Windows 电脑

**方法 A：使用系统自带的终端（Windows 10 及以上）**

1. 按 `Win 键`，搜索 `PowerShell` 或 `终端`，打开
2. 输入（替换为实际的用户名和 IP）：

```
ssh 用户名@服务器IP
```

3. 后续步骤同 Mac

**方法 B：使用 PuTTY（老版本 Windows）**

1. 浏览器打开 https://www.putty.org/ ，下载并安装 PuTTY
2. 打开 PuTTY，在 `Host Name` 处填入服务器 IP 地址
3. 点击 `Open`
4. 输入用户名，按回车
5. 输入密码，按回车
6. 看到命令提示符即连接成功

### 手机

可以在应用商店下载 SSH 工具：
- **苹果手机**：搜索安装 `Termius`（免费）
- **安卓手机**：搜索安装 `JuiceSSH`（免费）

打开后填入服务器 IP、用户名、密码即可连接。

## 第二步：上传安装文件到服务器

连接到服务器后，需要把安装文件传上去。

### 方法 A：直接下载（服务器能上网时）

如果安装文件在网上（比如公司发给您一个下载链接），直接在服务器上下载：

```bash
cd ~
wget 下载链接
```

或者用 git 克隆：

```bash
cd ~
git clone 仓库地址
```

### 方法 B：从自己电脑传到服务器

**Mac / Windows 10+：** 打开自己电脑的终端，输入（注意这个命令在**自己电脑**上执行，不是在服务器上）：

```bash
scp -r 本地文件夹路径 用户名@服务器IP:~/
```

**举例：** 把桌面上的 `menzhen` 文件夹传到服务器：

```bash
scp -r ~/Desktop/menzhen root@192.168.1.100:~/
```

**Windows 老版本：** 可以用 [WinSCP](https://winscp.net/) 软件，是图形化的文件传输工具，像"文件管理器"一样拖拽文件。

---

## 第三步：运行安装向导

文件传到服务器后，在服务器上（SSH 连接的那个窗口里）执行：

```bash
cd ~/menzhen
bash start-wizard.command
```

屏幕会显示类似这样的内容：

```
================================================
  门诊系统安装向导
================================================
  系统: Ubuntu 22.04
  本机IP: 192.168.1.100
  运行模式: 服务器模式（无桌面）

  请在您自己电脑的浏览器中打开:

    http://192.168.1.100:9527

  如果打不开，请检查防火墙是否放行了 9527 端口
================================================
```

---

## 第四步：在自己电脑的浏览器中操作

1. 打开您自己电脑（或手机）的**浏览器**（Chrome、Safari、Edge 都行）
2. 在地址栏输入屏幕上显示的地址，例如：

```
http://192.168.1.100:9527
```

3. 看到「门诊系统安装向导」页面后，按页面提示一步一步操作即可
4. 操作和桌面版完全一样，全程中文引导

## 常见问题

### 浏览器打不开向导页面？

**原因 1：防火墙没放行端口**

在服务器上执行：

```bash
# Ubuntu / Debian
sudo ufw allow 9527
sudo ufw allow 80

# CentOS / RHEL
sudo firewall-cmd --add-port=9527/tcp --permanent
sudo firewall-cmd --add-port=80/tcp --permanent
sudo firewall-cmd --reload
```

**原因 2：不在同一个网络**

您的电脑和服务器必须在同一个局域网内（连着同一个路由器或交换机）。如果服务器在云上（阿里云、腾讯云等），需要在云控制台的"安全组"里放行 9527 和 80 端口。

**原因 3：IP 地址不对**

在服务器上输入 `hostname -I` 确认 IP 地址，用显示的第一个地址。

### SSH 连不上？

- 确认服务器已开机并联网
- 确认 IP 地址正确（在服务器面前输入 `hostname -I` 查看）
- 确认 SSH 服务已启动：`sudo systemctl status sshd`
- 如果没有启动：`sudo systemctl start sshd`

### 提示"Permission denied"？

密码输错了，请重试。注意：
- 输密码时屏幕**不会显示任何字符**（没有星号），这是正常的
- 直接输完密码按回车即可

### 安装完成后，其他电脑怎么访问系统？

安装完成后，向导页面会显示访问地址（例如 `http://192.168.1.100`）。局域网内任何电脑或手机，在浏览器输入这个地址就能使用门诊系统。
