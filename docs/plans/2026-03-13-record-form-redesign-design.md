# 诊疗记录表单 UI 重设计方案

> 日期：2026-03-13
> 状态：已确认

## 背景

当前 `RecordForm.tsx`（1440 行）存在以下 UI 问题：

1. **字段宽度不一致**：患者 `flex:1`、日期 `width:200px`、主诉全宽、脉象全宽、舌象 `flex:1 + flex:2` — 无统一网格
2. **缺乏逻辑分组**：基本信息、四诊信息、诊断治疗、附件备注混在一起，无视觉分区
3. **视觉层次扁平**：所有字段等权重，无法快速定位
4. **AI 结果卡片风格不一致**：舌象分析和辩证论治使用不同渐变色和布局
5. **诊断+治疗并排等高**：22 行 TextArea 等高，治疗方案大面积留白
6. **移动端仅简单 column 堆叠**，未优化信息密度

## 使用场景

**边问诊边录入** — 医生一边问诊一边填写，需要按问诊流程排列字段，快速定位，减少滚动。

## 设计决策

| 决策项 | 选择 | 理由 |
|--------|------|------|
| 整体布局 | 线性卡片流（4 张卡片） | 按问诊流程从上到下，结构清晰 |
| 分组方式 | 卡片分区（Card + 标题 + 色彩标识） | 视觉分隔明确，优于分割线 |
| 诊断/治疗 | 上下堆叠 | 诊断全宽阅读更舒适，治疗按需给高度 |

## 卡片分区设计

### Card 1 · 基本信息（蓝色 #1677ff）

```
┌──────────────────────────────────────────────┐
│ 🔵 基本信息                                   │
├──────────────────────────────────────────────┤
│ [患者选择 flex:1          ] [就诊日期 w:200px] │
│ [主诉 TextArea rows=2 全宽                   ] │
└──────────────────────────────────────────────┘
```

- 患者 Select `flex:1` + 就诊日期 DatePicker `width:200px` 同行（移动端改为纵向堆叠，日期 100%）
- 主诉 TextArea 全宽，rows=2

### Card 2 · 四诊采集（绿色 #52c41a）

```
┌──────────────────────────────────────────────┐
│ 🟢 四诊采集                                   │
├──────────────────────────────────────────────┤
│ [脉象 Select 全宽                            ] │
│ ┌─ 脉象详情卡片（展开时显示）──────────────┐  │
│ │ 弦脉 [弦类脉]                             │  │
│ │ 特征：端直以长...  临床意义：肝胆病...    │  │
│ └───────────────────────────────────────────┘  │
│                                                │
│ [舌象图片 w:160px] [舌象描述 flex:1          ] │
│                    [🤖 分析舌象] [🔄 重新分析] │
│                                                │
│ ┌─ AI 分析结果（蓝色渐变卡片）──────────────┐ │
│ │ 🤖 舌象 AI 分析结果                       │ │
│ │ 分析内容（Markdown）...                    │ │
│ │ 以上分析由 AI 生成，仅供参考               │ │
│ └───────────────────────────────────────────┘ │
└──────────────────────────────────────────────┘
```

- 脉象全宽 Select，**选中脉象后**条件渲染详情卡片（非折叠面板，`selectedPulse` 存在时直接显示）
- 舌象图片 `w:160px` + 描述 `flex:1` 同行；描述 TextArea rows=3
- AI 分析按钮（分析舌象 / 重新分析）放在舌象描述的 label 中
- AI 分析结果统一使用蓝色渐变卡片，`max-height: 400px` 可滚动（防止超长结果撑开页面）

### Card 3 · 诊断治疗（橙色 #fa8c16）

```
┌──────────────────────────────────────────────┐
│ 🟠 诊断治疗                                   │
├──────────────────────────────────────────────┤
│ [诊断 TextArea 全宽 rows=20]                  │
│ [🤖 AI辅助分析] [已有分析]                    │
│                                                │
│ [治疗方案 TextArea 全宽 rows=6]               │
└──────────────────────────────────────────────┘
```

- 诊断全宽，桌面端 rows=20（从 22 缩减），移动端 rows=12（从 10 增加）
- AI 辅助分析按钮和「已有分析」Tag 放在诊断 label 中（与现有逻辑一致）
- 治疗方案全宽，桌面端 rows=6，移动端 rows=4（从 22/10 大幅缩减，匹配实际内容量）
- 上下堆叠，不再并排

### Card 4 · 备注附件（灰色 #8c8c8c）

```
┌──────────────────────────────────────────────┐
│ ⚪ 备注附件                                    │
├──────────────────────────────────────────────┤
│ [备注 TextArea half] [附件上传 half          ] │
└──────────────────────────────────────────────┘
```

- 备注 + 附件并排各 50%
- 移动端改为纵向堆叠

### 操作按钮

```
[保存] [开方] [取消]
```

- 桌面端：左对齐，`Space` 组件，与现有行为一致
- 移动端：`display: flex` 等宽铺满，取消按钮可省略（用返回手势代替）

### 处方区域（编辑模式）

保持现有设计，处方列表在按钮下方。

## 统一规范

### 字段宽度（3 种）

| 类型 | CSS | 使用场景 |
|------|-----|----------|
| `full` | `flex: 1` | 患者、主诉、脉象、诊断、治疗 |
| `half` | `flex: 1`（两个并排） | 备注、附件 |
| `w200` | `width: 200px` | 就诊日期 |

### 间距

| 元素 | 间距 |
|------|------|
| 卡片之间 | `12px` |
| 卡片内 padding | `20px 24px`（移动端 `14px 16px`） |
| 字段行之间 | `16px`（移动端 `12px`） |
| 字段行内 gap | `16px` |

### 卡片标题

- 左侧色块图标（20x20 圆角正方形）+ 标题文字
- 下方 1px `#f0f0f0` 分割线
- 每张卡片一个主题色

### AI 结果卡片（统一样式）

用于舌象分析和辩证论治分析：

- 容器：`border-radius: 8px`，蓝色渐变背景
- 头部：`#1677ff → #4096ff` 渐变，白色图标+标题
- 内容：Markdown 渲染，`max-height: 400px` 可滚动
- 底部：虚线分割 + 灰色 disclaimer

## 移动端适配

| 元素 | 桌面端 | 移动端 |
|------|--------|--------|
| form-row 方向 | `row` | `column` |
| `w200` 字段 | 固定 200px | `width: 100%` |
| 舌象图片+描述 | 横向排列 | 纵向堆叠 |
| 诊断 TextArea | rows=20 | rows=12 |
| 治疗 TextArea | rows=6 | rows=4 |
| 备注+附件 | 横向并排 | 纵向堆叠 |
| 卡片 padding | 20px 24px | 14px 16px |
| 卡片间距 | 12px | 8px |
| 按钮 | `Space` 左对齐 | `flex` 等宽铺满 |

## 实现范围

### 需要修改的文件

- `web/src/pages/records/RecordForm.tsx` — 主要重构目标

### 不修改的部分

- RecordList 页面（已有良好的桌面/移动端适配）
- 后端 API（无变更）
- PrescriptionModal / PrescriptionPrint 组件
- FileUpload 组件
- AI Drawer（辩证论治抽屉保持不变）

### 重构策略

1. 将 Card 分区抽取为 `SectionCard` 组件（title, color, children）
2. 统一 form-row 样式为 CSS class 而非 inline style
3. AI 结果卡片抽取为 `AiResultCard` 组件（复用于舌象和辩证）
4. 保持所有业务逻辑不变，仅调整布局和样式
