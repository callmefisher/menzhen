# 经络数据同步工具

## 标准化流程

### 1. 使用校准工具调整经络

打开浏览器访问：
```
http://<your-server>/lu-calibrator-export.html
```

### 2. 导出数据

1. 在左侧校准工具中调整经络路径点
2. 在右侧面板中配置穴位索引映射
3. 点击"生成数据文件"预览
4. 点击"导出到正式环境"
5. 打开浏览器控制台，复制输出的 JSON 数据

### 3. 同步到正式环境

#### 方法1：使用脚本自动同步

```bash
cd /Users/xiayanji/qbox/menzhen/web/scripts

# 将复制的 JSON 数据保存到文件
echo '<粘贴 JSON 数据>' > /tmp/lu-data.json

# 运行同步脚本
node sync-meridian-data.js LU male < /tmp/lu-data.json
```

#### 方法2：手动复制

从导出工具生成的代码预览中，手动复制：
- 经络路径数据 → `src/pages/meridians/data/meridian-paths-male.ts`
- 穴位坐标数据 → `src/pages/meridians/data/acupoint-positions-male.ts`

### 4. 构建并部署

```bash
cd /Users/xiayanji/qbox/menzhen/web
npm run build
./deploy.sh
```

## 数据格式

### 经络路径数据
```typescript
'LU': {
  // 手太阴肺经 — LU1@0, LU2@1, LU3@5, ..., LU11@26
  path: [
    [-0.138, 1.296, 0.089],  // 0
    [-0.141, 1.330, 0.075],  // 1
    // ... 更多点
    [-0.373, 0.797, 0.178],  // 26 (LU11 少商)
  ],
},
```

### 穴位坐标数据
```typescript
// 手太阴肺经 (LU) - 坐标与经络路径对应
'LU1': [-0.138, 1.296, 0.089],  // 0
'LU2': [-0.141, 1.330, 0.075],  // 1
// ...
'LU11': [-0.373, 0.797, 0.178],  // 26（末端）
```

## 注意事项

1. **穴位坐标必须与经络路径点对应** - 使用相同的索引
2. **男女模型数据分开** - male/female 分别存储
3. **路径点数量 >= 穴位数量** - 确保每个穴位都有对应的路径点
4. **末端穴位** - 确保最后一个穴位对应路径的最后一个点
