5 交互规格
详细的交互行为和技术参数

🧭 返回导航栏（RecordForm）

  • ✓显示条件：URL 含 from=patient，或编辑模式下记录关联了患者且来源为患者详情
  • ✓内容：患者姓名首字头像 + 「返回患者详情」按钮
  • ✓状态记录：处方保存/编辑时记录最后操作的 prescriptionId
  • ✓点击行为：navigate(`/patients/${patientId}`, { state: { highlightRecordId, highlightPrescriptionId } })
  • ✓按钮强化：处方保存成功后，按钮变为实色背景 + 脉冲动画，吸引注意力

✨ 记录高亮（PatientDetail — 蓝色）

  • ✓触发：location.state.highlightRecordId 存在时
  • ✓展开：自动加入 expandedRecords Set
  • ✓滚动：scrollIntoView({ behavior: 'smooth', block: 'center' })
  • ✓样式：蓝色左边框 #1677ff + 浅蓝背景 rgba(22,119,255,0.12) + 脉冲动画
  • ✓消退：15s 后移除高亮，history.replaceState 清除 state

🔶 处方高亮（PatientDetail — 橙色）

  • ✓触发：location.state.highlightPrescriptionId 存在时，在已展开的记录中匹配
  • ✓样式：橙色左边框 #fa8c16 + 浅橙背景 rgba(250,140,22,0.12) + 脉冲动画
  • ✓角标：匹配的处方显示「刚操作」/「已修改」橙色 badge
  • ✓滚动：先滚动到记录，记录展开后再微调滚动到处方位置
  • ✓消退：与记录高亮同步，15s 后一起移除
场景 导航 state 记录高亮 处方高亮
新建记录 + 新增处方 → 返回 { recordId, rxId } 蓝色 橙色
编辑处方 → 返回 { recordId, rxId } 蓝色 橙色 + 「已修改」
新建记录无处方 → 返回 { recordId } 蓝色 无
从记录列表编辑 → 保存 不适用（走现有逻辑） 跳转 RecordList 高亮（已有）

改动范围总结

RecordForm.tsx
+ 返回导航栏 + 处方 ID 追踪
记录 from=patient 来源 + lastSavedPrescriptionId
PatientDetail.tsx
+ 双层高亮定位

PrescriptionModal
onSuccess 回传 rxId

兼容性
完全向后兼容
