改动汇总

页面改动方式隐藏列移动端
DrugList responsive: md → lg 预警阈值、最后更新（<992px 隐藏） 不影响
HerbSearch responsive: md → lg 分类、来源（<992px 隐藏） 不影响
FormulaSearch responsive: md → lg 来源（<992px 隐藏） 不影响
RecordList 操作列 width 200→160 无 不影响（移动端仍为 100px）

技术说明：Ant Design 的 responsive: ['lg'] 表示仅在 ≥992px 时显示该列。 768px~992px 的平板会自动隐藏这些列，而 ≥992px 的桌面端正常显示。移动端（<768px）使用卡片布局，不受 responsive 影响。
